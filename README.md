# Human_Activity_Recognistion_ML-AI
We will collect our own smartphone motion data, compare it to a public HAR dataset and then train machine learning models and deep learning models to recognise activities. We then test how robust the models are under different conditions (e.g. device placement)

Activities: walking, walking upstairs, walking downstairs (plus others from the public dataset including sitting and standing)

Device placements (group data): waist, trouser pocket and in hand.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

How to run:

Step 1:
Clone Repo to your external editor.

Step 2:
Navigate to the folder 'src/models'.

Step 3:
Identify which model you want to run.

Step 4:
Click on the top most cell and press on the 'Run All' button at the top.

Step 5:
The model will now run and you can view all the outputs in the .ipynb file (The graphs are exported to the 'results' folder under the name of the model and dataset used to train and test the model)
